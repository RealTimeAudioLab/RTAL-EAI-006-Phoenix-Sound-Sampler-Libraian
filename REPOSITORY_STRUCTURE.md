# Repository Structure

```text
Phoenix-Librarian/
├── README.md
├── CHANGELOG.md
├── RELEASE_v1.0.0.md
├── REPOSITORY_STRUCTURE.md
├── .gitignore
├── src/
│   ├── PhoenixLibrarian.ps1

├── docs/
│   ├── ARCHITECTURE.md
│   ├── PHOENIX_INTEGRATION.md
│   ├── DEVELOPMENT_HISTORY.md
│   └── GITHUB_PUBLISHING.md
├── examples/
│   └── TestImport_BANK07.zip
└── images/
    └── .gitkeep
```

The normal Git repository should contain source, documentation, examples and screenshots. The packaged application ZIP belongs under **GitHub Releases**, not in the source tree.
